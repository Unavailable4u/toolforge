How it was built

ToolForge was built one small patch at a time from a written guide, and the repository keeps that guide.

Each patch is one commit with its own tests. PROGRESS.md says which patches are done and what each one left undone, and the guide in docs/guide is what an agent follows to produce the next patch.

The sandbox is MiniLocker, an earlier project of the same author, pinned as a submodule. ToolForge adds the verification, the registry and the MCP server on top of it.
