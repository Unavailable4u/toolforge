The tour: one tool, start to finish

Follow one request from an agent that has no tool for the job to a second agent reusing what the first one made.

The interactive version of this tour is planned and not built yet. This is the written version, and it takes about two minutes to read.

  1. 1 The agent asks, finds nothing, forges

    An agent needs to query a SQLite file. It searches the shelf and finds no match, so it writes a small tool with tests and a label saying it will read one file and use no network. It submits the tool.

  2. 2 The gates inspect and a person decides

    The gates read, build and test the tool and try to break it. A report says what the tool was seen doing. This tool asked for no network and no secrets, so nothing waits for approval and it can go on the shelf. A tool that did ask would wait for a person.

  3. 3 It runs in the locked room and gets reused

    Each call runs inside a sandbox, never on the host. Later a second agent searches the shelf, finds the same tool and calls it on a different database. Every step is in the ledger.
