The problem: a job that needs a tool nobody made

AI agents get stuck when the job needs a tool they were not given.

Say an agent is asked to read a file in an odd format, or to ask questions of a database it has never seen. There is no tool for that. Today one of two things happens.

  • A person stops what they are doing and writes the tool. That does not scale.
  • The agent writes some code and runs it straight away. Nothing records what the code did, and nothing remembers it for next time.

The second way is the risky one. Code that nobody checked could read your files, use your keys or call out to the internet, and you would have no record of it. ToolForge keeps what is good about the second way, an agent that can help itself, and adds the checks and the paper trail.
